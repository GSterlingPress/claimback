# ClaimBack — Walmart Solution Provider submission package

**Name:** ClaimBack
**Category:** Shipping / claims management
**Description:** Helps authorized Walmart Marketplace sellers identify, prepare, track and reconcile eligible Ship with Walmart shipment-protection claims.

## Authorization
OAuth 2.0 only after Walmart approval; explicit seller authorization; never collect Walmart passwords; least privilege.

## Requested capabilities
Shipment Protection claim submission/list/detail/history/additional information/documents plus minimum approved order/shipping data needed for shipment identity and eligibility.

## Demo
Connect sandbox/mock seller; run scan; show deterministic blocks; simulate eligible claim; show compliance log; demonstrate production hard lock.

## Questions for Walmart
Confirm scopes, any per-claim consent requirement, document retention/deletion requirements, and permitted pricing/compensation model.
